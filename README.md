# 🐿️ The Whimsical Squirrels of Headington Hill

A whimsical, child-friendly single-page website dedicated to the beloved squirrels of Headington Hill at Oxford Brookes University.

## 🌿 Live Site

Once deployed, your site will be available at:
`https://<your-username>.github.io/<repository-name>/`

## 📁 Project Structure

```
headington-squirrels-site/
├── index.html          # Main website (single page)
├── styles.css          # All styling
├── app.js              # Interactions, audio, gallery logic
├── README.md           # This file
└── Apic/               # All images and audio assets
    ├── *.JPG           # Squirrel photographs
    ├── *.png           # Icons and map assets
    ├── Guilly.jpeg     # The Wildlife Observation Society reveal
    ├── Acorns on the Quad.mp3   # Background music
    └── ...
```

## 🚀 Deploying to GitHub Pages

1. Create a new repository on GitHub (e.g. `headington-squirrels`)
2. Upload all files from this folder to the repository root
3. Go to **Settings → Pages**
4. Under **Source**, select **Deploy from a branch**
5. Choose **main** branch, **/ (root)** folder → click **Save**
6. Your site will be live at `https://<username>.github.io/headington-squirrels/`

## ✨ Features

- 🐿️ Three squirrel profile cards: Professor Pipkin, Barnaby "The Bold", Lady Clementine
- 🗺️ Interactive campus territory map
- 📸 Photographic archive gallery
- 🎵 Background music player (Acorns on the Quad)
- 🍃 Animated woodland breeze toggle
